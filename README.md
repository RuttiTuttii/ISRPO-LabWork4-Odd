# ISRPO LabWork 4 — Команда Нечетных (Модели данных, БД, Фильтрация и Пагинация)

Лабораторная работа №4 по дисциплине **МДК.02.02 Инструментальные средства разработки программного обеспечения (ИСРПО)**.  
Тема: **Разработка и интеграция модулей проекта (командная работа)**.

## Текущая версия
**v1.0.0** — Первый стабильный релиз модулей модели данных и логики выборки.

## Участники и задачи (Нечетные задачи по Варианту 1):
* **Участник 1 (Задача 1):** Создание модели данных (`Category`, `Product`, `Customer`, `Order`, `OrderItem`) и настройка контекста БД (`AppDbContext`, EF Core SQLite, сидирование `DbInitializer`).
* **Участник 3 (Задача 3):** Разработка логики фильтрации, сортировки и пагинации (`QueryParameters`, `ProductFilter`, `PagedResult<T>`, `QueryableExtensions`).

## Инфраструктура и качество:
* **CI/CD:** Настроен пайплайн GitHub Actions (`.github/workflows/ci.yml`), выполняющий автоматическую сборку и прогон xUnit тестов при пушах и PR.
* **Тестирование:** 18 модульных и интеграционных тестов в проекте `LabWork4.Odd.Tests` (валидация моделей, LINQ-фильтрация, постраничный вывод).

## Сборка и запуск:
```bash
dotnet restore
dotnet build
dotnet test
dotnet run --project src/LabWork4.Odd/LabWork4.Odd.csproj -- all
```

## Профили запуска (Properties/launchSettings.json):
* `1` — Вывод всех категорий и связанных товаров
* `2` — Демонстрация пагинации (страницы каталога)
* `3` — Фильтрация по категории и сортировка по цене
* `4` — Поиск по ключевому слову
* `all` — Запуск всех сценариев
